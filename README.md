# MilliyCerti.uz — prototip (paketsiz)

Ishga tushirish: `cd milliycerti && python3 -m http.server 8000` → http://localhost:8000
(index.html ni to'g'ridan-to'g'ri ochish ham mumkin.)

Fayllar: index.html (bosh sahifa), practice.html (mashq), exam.html (vaqtli mock),
data.js (sozlamalar + original savollar), app.js (umumiy UI), styles.css (dizayn tizimi).

Eslatma: npm registry bu muhitda bloklangan edi, shuning uchun Next.js/Supabase o'rniga
bog'liqliksiz prototip qurildi. Ma'lumotlar brauzer localStorage'ida saqlanadi.
Imtihon tuzilmasi va CEFR chegaralari rasmiy hujjat bilan TASDIQLANMAGAN (data.js → MC_CONFIG).
